What this is

A small program that watches one folder on your Desktop, sorts whatever you drop into it by camera and date, and keeps a permanent, checkable record that nothing got lost or corrupted along the way.

It never deletes your originals. A copy goes to the archive, gets checked byte-for-byte against the original, and only then does the original folder get moved aside — never removed. If anything's uncertain at any step, it stops and tells you, rather than guessing.

Quick start

  1. Drop your files in Put a folder of photos/videos (or loose files) straight into Shenzhen Sorting Facility on your Desktop. Any arrangement is fine — one folder, several, or files with nothing around them.

  2. Open the control panel Double-click your Shenzhen Sorting Control shortcut.

  3. Press the big green button Labeled Start Parcel Distribution — this is Manual Onboarding. You get a 10-second hold first — the button turns into Stop during that window in case you meant to press something else. Let it run out, and sorting begins for real.

  4. Check the receipt When it's done, open Receipt Center Console and read the top of the newest receipt. It tells you straight away whether everything verified, or whether something needs your attention.

Glossary

Shenzhen Sorting Facility
The Desktop folder you drop things into. Nothing else needs to happen here — the program watches it.
Dump folder
Any one folder you drop in — a single batch, like "iPhone July" or "Fuji Weekend". Each one gets sorted and accounted for on its own.
Warehouse
The permanent archive on the S: drive. Organized by camera first, then Year → Month. You're free to reorganize inside it by hand — see "Trip folder" below — Compliance Check is designed around that.
Trip folder
A folder you make yourself, anywhere inside the Warehouse (e.g. 2026 July - Santa Maria), by copying files you like out of Browse Month. Entirely your own convention — the program doesn't require or manage these, and copying into one never affects the originals still sitting in their camera folders.
Shipped
A folder inside the Sorting Facility. Once every file in a dump folder is safely copied and verified, the original folder moves here — not deleted, just moved aside, so you can tell at a glance what's fully done.
Receipt
A record of one sort — what came in, where it went, whether it all checked out. Written every single time, success or not.
Receipt Center Console
The Desktop folder where every receipt lands. The first place to check after any sort.
Glove Box
A folder inside the Center Console. Once you've personally read a receipt, you can drag it in here as your own "seen it" pile. Purely for you — it has no effect on anything the program tracks.
Manual Onboarding
Sort right now, by hand, instead of waiting on the usual timers — because you're right there confirming the files are actually done arriving.
Compliance Check
Confirms every file the Warehouse is supposed to have is still there. If you've reorganized things into your own folders inside the Warehouse, that's fine — it looks for content anywhere inside, not just where it started. Compares against the last time you ran it, so something you deliberately removed only gets flagged once.
Delivery Check
Confirms everything sitting in Shipped is safely backed up in the Warehouse — the check to run before you delete or clean out Shipped.
Browse Month
A read-only way to see one Year/Month across every camera and device at once, instead of opening each camera's folder separately. Pick from a list of months that actually have content — it opens a temporary folder in Explorer built from the real files (no extra copies, no disk space used), so you can look through everything together and copy out whatever you want into a Trip folder. Nothing in the Warehouse is touched. Screenshots, screen recordings, and unidentified files are left out of the view by default (still fully archived either way) so it stays focused on real photos.
Repair Folders
Rebuilds the Sorting Facility, Shipped, Receipt Center Console, and Glove Box if any of them get deleted, renamed, or moved — so the program doesn't just quietly stop working. The Warehouse itself is treated more carefully: it's only rebuilt automatically if the ledger has no prior archived content on record. If the ledger remembers files but the Warehouse folder is missing, Repair Folders refuses and tells you why instead of guessing — that could mean the drive disconnected, not that the archive is actually gone.
Clear / Not clear
The verdict at the top of a Compliance or Delivery Check receipt. Clear means go ahead. Not clear names exactly what wasn't confirmed, and why.
Verified and sorted
The count on a sorting receipt — X of Y files copied and independently confirmed byte-for-byte, not just "copy said it worked."

When do I use what

I just got back from a trip with a full memory card.

Drop the whole card's folder straight into the Sorting Facility. Open the panel, press Start Parcel Distribution, let the ten-second hold run out. Check the receipt when it's done.

I want to delete or clean out what's sitting in Shipped.

Run Delivery Check first, every time. Clear means every original in there is confirmed backed up — safe to remove. Don't skip this step just because it looks obviously fine.

Something in the Warehouse looks off, or I just want peace of mind.

Run Compliance Check. Tick Deep verify if you want it to re-read actual file content, not just confirm things are present — worth doing occasionally, especially before anything that would be hard to undo.

I reorganized photos into my own folder inside the Warehouse.

Nothing to do. Compliance Check already looks for content anywhere in the Warehouse before calling anything missing — your own reorganizing was designed in from the start, not an afterthought.

I want to pull together everything from a trip, across all my cameras.

Press Browse Month, pick the Year/Month. Everything from that month, across every camera and device, opens together in one Explorer window — copy whatever you want out into a Trip folder you make yourself inside the Warehouse. The originals stay exactly where they are.

One of the working folders got deleted, renamed, or moved by accident.

Open Advanced Settings and press Repair Folders. It rebuilds Sorting Facility, Shipped, Receipt Center Console, and Glove Box on the spot. The Warehouse is the one exception — if it's missing but the ledger remembers content, Repair Folders refuses and tells you why rather than risk quietly starting a second, empty archive.

The countdown says "ready in 04:23" and I don't want to wait.

Press Start Parcel Distribution instead — it only needs a couple of seconds, not the full timer, because you're right there vouching the transfer is actually finished.

If something needs attention

A receipt that isn't Clear or says Needs attention is not an emergency. Nothing gets deleted automatically, ever — anywhere in this system.

Read the receipt's detail section — it names the exact file, which folder it was expected in, and whether the original is still sitting safely in Shipped. If it's still there, nothing was actually lost; it just needs re-sorting.

Rule of thumb

When in doubt, don't delete anything and don't press Delivery Check's "go ahead" as a formality — read what it actually found first.

Troubleshooting

What you're seeingWhat's going on
Manual Onboarding is grayed outA transfer or check is already running. Wait for it to finish — Safe Stop is the only button that stays live.
Countdown isn't movingIt's deliberately paused while a transfer or check is active — nothing wrong, it resumes once that finishes.
"Nothing waiting" but I just dropped files inGive it a moment — files need to sit untouched briefly before they're treated as finished arriving. Manual Onboarding doesn't wait on this.
Paused — safety condition, won't go awayFix the underlying cause first (usually free space or a disconnected drive), then press Start/Resume — it re-checks everything before continuing.
A file landed in the wrong-seeming categoryNot data loss — everything is still hash-verified and accounted for. Move it within the Warehouse if you'd prefer it elsewhere; Compliance Check will find it there next time.
Warehouse button won't open, or Repair Folders refuses to rebuild itBy design — it's checking whether the drive is really disconnected/the folder really gone versus the ledger still remembering archived content. Confirm S:\ is connected before doing anything else.
A file I expected in Browse Month isn't showing upScreenshots, screen recordings, and unidentified files are excluded from the view by default — they're still fully archived, just not shown there. Everything else should appear; if something's genuinely missing, run Compliance Check.
